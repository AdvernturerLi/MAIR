# 探索、经验构建和先验验证：论文实验协议 v2

状态：设计冻结前版本；尚未启动探索。用户授权两套方法分别构建经验；当前仅允许服务器本地探索与统计，不向外部API发送验证图、工具序列、失败率或IQA统计。已有pilot.py默认关闭外部蒸馏。本协议增加原小试未覆盖的关键关系，旧4图小试仅作为工程预检，不承担论文结论。

## 1. 研究问题 → 可检验假设

H1 跨阶段约束：压缩→成像→场景能否在较小搜索空间下保持或提高质量？需要验证顺序本身的作用，并在同一MAIR系统中消融阶段约束。MAIR对AgenticIR总体比较仅是动机和外部参照。

H2 阶段内经验：不同退化上下文下最优顺序是否不同，特别是无超分的噪声/模糊与有超分的噪声/模糊/低分辨率？这决定为何除了三阶段先验还需要离线经验。

H3 经验迁移：各自按原方法依据生成的经验，能否在未用于构建经验的图像上改善质量或降低搜索开销？AgenticIR学习全局任务顺序，MAIR学习阶段内顺序，分别评价、分别冻结。

完整逻辑链为：baseline行为证据 → 独立验证上的顺序效应 → 分方法评价统计 → 有依据的经验条目 → 固定经验的测试对照 → 质量/成本及失败案例解释。任一环节没有结果则保留为待检验假设。

## 2. 数据角色与覆盖

- 经验候选数据：已有validation的10个HQ源，必须与test的20个HQ源在ID及内容哈希上均不重合。test160不产生经验、不选择规则、不选择示例来调规则。
- 工程小试：084、054两个验证HQ × noise+blur、rain+haze，两对顺序完整工具枚举，共196次前缀缓存工具调用、160叶子。作用仅为检查工具、七项IQA、DepictQA、断点续跑和时间成本。
- 核心阶段内探索：10HQ × noise+blur、rain+haze、blur+low-resolution；每对保留当前全部工具，合计1470次调用、1200叶子。小试结果满足相同配置和哈希时复用，不重复扣费。
- 跨阶段探索：10HQ × jpeg+noise、low-light+noise、haze+low-resolution、rain+blur；完整双任务排列和全部当前工具，共1870次调用、1520叶子。由此核心双任务七种双任务组合，共3340次调用、2720叶子；不包含现有第八类三任务的7440次调用。
- 条件规则补集：在同10个验证HQ单独生成noise+blur+low-resolution；沿用并冻结现有退化参数、合成顺序、种子与源哈希，作为新增协议数据，不能伪称原有validation。成像三任务全部6种顺序、工具数5×4×5，每HQ744次调用/600叶子，10HQ额外7440次。此项优先采用下一节的匹配工具方案降低成本；若不执行，不产生这条条件经验。
- 真实域验证：当前合成集无法复现原文五套真实验证集的经验来源。论文需明确为受控合成数据上的经验重建；若以后补真实数据，单独评估跨域适用性。

不把同一HQ的不同退化视为独立图像样本。可用按HQ留一验证检验规则稳定性，最终经验由全部10HQ构建，再在test20HQ上检验泛化。当前没有额外验证源用于独立调参，因此阈值预先固定，禁止根据测试反复调整。

## 3. 用匹配实验识别顺序效应

完整双任务探索在每张输入上遍历全部工具对，两种顺序使用相同工具实例、权重与参数。对每个固定工具对计算顺序差值，再对工具对和HQ汇总，避免“顺序A用了强工具、顺序B用了弱工具”的混淆。

条件三任务先选3套预先固定、在所有任务均有模型的工具组合：全Restormer系列配固定HAT超分、全X-Restormer、MPRNet去噪/去模糊配固定SwinIR-PSNR超分。逐组合验证注册名与权重可用性；实际名称在启动前manifest冻结，不能因结果换组合。每组合每HQ枚举6种顺序，最多15个非空排列前缀；3组合×10HQ至多450次工具调用、180叶子，跨组合可复用完全相同的前缀。这是预选工具子集的控制实验，不称全工具穷举。

顺序评价报告每项IQA、综合分、固定工具匹配差值、胜负/平局比例和按HQ聚类区间，不只展示最优候选。固定三阶段顺序的候选子集与全顺序候选集合可从同一缓存比较，报告最优可达质量差、平均质量和候选数压缩；全集合的最优值数学上不会更差，不能用这一比较宣称约束提高全局最优质量。它回答的是限制空间造成多少机会损失。

双任务优先完成；条件三任务是否扩展以工程小试实测秒/调用和GPU余量决定。总预算为3340+最多450次工具调用，不含评价和重试；小试包含在3340中。对比原80完整枚举10780，先覆盖机制需要的关系，减少昂贵且不回答条件规则的原三重组合。若预算只能做部分数据，要按预先固定HQ顺序截取，保留覆盖与局限，不能挑高分样本。

## 4. 同一轨迹池 → 两条独立评价链

共享只限工具生成结果和文件校验，不能共享最终经验文本。

AgenticIR：本地DepictQA逐候选评价待修复退化，按原探查逻辑以medium/high/very high为残留失败。按任务集合、顺序、工具配置保存分母、失败数、置信区间及典型冲突；不以MAIR七项分数代替原生失败率。记录每种退化失败率和联合失败率，明确最终采用原实现哪一项作排序，避免事后换指标。

MAIR：PSNR、SSIM、LPIPS、DISTS、MANIQA、CLIP-IQA、MUSIQ全部有效才纳入完整综合分。LPIPS/DISTS取负方向；在同输入的固定完整候选池内逐指标z-score后求和，标准差为0时贡献0。此归一化池是本复现的明确实现约定，不能声称作者未公开的细节已被精确恢复。分析H1候选子集时沿用同一完整池的归一化参数，不能对各子集重新标准化后比较。保持单项指标结果，检查结论对只用全参考指标、等权综合分的敏感性。

尺寸改变仍保留有效输出；与已有test协议一致，仅算需参考图的指标时将预测对齐HQ，并记录原尺寸和resize标记。NR指标的输入尺寸策略固定并披露；原图不覆盖。所有失败分开计数，禁止把工具失败当成图像质量差混进平均分，不能静默漏失难例。

## 5. 统计 → 经验条目 → 蒸馏

每条经验带证据表：适用任务及上下文、候选顺序、HQ数/叶子数、比较依据、效应量/不确定性、失败率、工具覆盖、反例、源manifest与统计哈希。MAIR只从同阶段关系生成经验，不从跨阶段结果反向改写三阶段硬约束；AgenticIR保存全局任务顺序建议。没有noise+blur+SR实证时，不把两个pair关系自动拼成三任务规则。

预先采用按HQ留一的方向稳定性检查：每个折都重算经验关系，并记录方向一致率；证据冲突或少样本时保留“不确定/不提供规则”，不强制形成漂亮的全序。阈值与平局容差在看结果前写入配置，原始计数和单项分数始终保留。

暂不外传时只形成本地统计及可审计的候选规则，不能把人工摘要/模板规则称为原文LLM蒸馏。正式蒸馏有两条后续路径：已有可用本地语言模型进行文本蒸馏并记录模型/提示词；或用户以后明确授权外部统计文本蒸馏。当前两者均未执行。模型只改写统计证据，不重新推断图像，核验没有编造条件或反转优劣。AgenticIR与MAIR经验文件独立命名、独立版本和来源哈希。

## 6. 冻结经验 → 系统级消融

| 系统 | 阶段先验P | 经验E | 回答的问题 |
|---|---|---|---|
| MAIR | 开 | 关 | 已有baseline；有约束无经验 |
| MAIR | 关 | 关 | 与上一行比较，识别阶段先验作用 |
| MAIR | 开 | 开 | 与第一行比较，识别原生阶段内经验作用 |
| MAIR | 关 | 开 | 扩展交互实验，谨慎定义阶段内规则仍有效但不硬排阶段 |
| AgenticIR | 原生规划 | 关 | 已有baseline |
| AgenticIR | 原生规划 | 开 | 原生全局顺序经验作用 |

前三个MAIR条件及AgenticIR有无经验是核心；第四个MAIR条件作为扩展。关闭先验必须真正允许跨阶段自由排序，不只是移除提示词后仍执行阶段拼接。其提示词差异、计划次数、agenda和排序输出合法性全部记录。为尽量隔离P效应，MAIR P+/P−均使用一次完整agenda排序调用，仅开关跨阶段约束；原baseline按阶段调用排序，因此需要生成匹配的P+控制，不能直接把旧P+与新P−称为严格单变量比较。若保留原分阶段流程，结论应称“分阶段规划机制”的联合效果，并披露调用次数差异。

固定32工具、权重、粗/细感知、比较器、停止阈值、输入/指标协议及API参数。若服务模型版本不可锁定，保存返回模型标识、时间和重试；按样本交错运行新对照减少时间漂移影响。有无经验只改变相应经验注入。相同HQ/退化配对分析，按20HQ聚类bootstrap；报告PSNR/SSIM、7IQA可用项、调用数、最终链步骤、逆序、任务遗漏/额外识别、错误和尺寸变化。时间为部署相关结果，补充模型加载和重试成本。

测试集已用于观察baseline及提出本协议，所以后续消融是预先冻结方案后的确认性复现评估，不能宣称完全未接触的盲测。若要做严格新数据确认，需另立不参与当前分析的新HQ集合。

1. 冻结协议、任务映射、源图哈希、模型/工具manifest、归一化与评价阈值。
